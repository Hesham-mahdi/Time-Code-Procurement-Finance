# Time Code — نظام ربط المشتريات بالمالية

موقع عربي لربط مدير المشتريات بالمالية:
- المشتريات تنشئ المشروع وترفع **فاتورة ضريبية** أو **عرض سعر** بالصورة ونسبة السداد المطلوبة.
- المالية تعتمد وتسدد وترفق **إيصال السداد**، والمشتريات يوصلها إشعار فوري.
- لو المستند عرض سعر، المشتريات ترفع **الفاتورة الضريبية** بعد السداد، وقيمتها بتحل محل قيمة العرض.
- **مركز تكلفة** لكل مشروع: التقديري (العرض المالي) مقابل الملتزم به والمسدد فعلاً، لكل بند. والمبالغ قبل الضريبة.
- مدير النظام (المالية) يضيف المستخدمين بكلمات مرورهم ويحدد صلاحياتهم.

الخطة والمتطلبات: [docs/PLAN.md](docs/PLAN.md) · البحث والمقارنة بالأنظمة العالمية: [docs/RESEARCH.md](docs/RESEARCH.md)

### الإصدار 2 (مبني على Procore / Coupa / Precoro / Oracle ومتطلبات ZATCA)
- **قراءة رمز QR** من صورة الفاتورة الإلكترونية وتعبئة البيانات تلقائياً.
- **أكتر من فاتورة ضريبية لعرض السعر الواحد**: فاتورة عن كل دفعة مقدمة + فاتورة نهائية.
- **ضريبة المدخلات**: "قابلة للاسترداد" منفصلة عن "معلّقة بانتظار الفاتورة"، وتقرير شهري.
- **التحقق من الرقم الضريبي والآيبان السعودي**، وتحذير **المستندات المكررة**.
- **المحتجزات** (ضمان حسن التنفيذ) والإفراج عنها.
- **تعديلات الميزانية بسبب** مع قفل التقديري الأصلي، و**المتوقع عند الإنجاز**.
- **فحص الميزانية وقت الاعتماد**، والتجاوز يحتاج سبب ويبلّغ الإدارة.
- **صندوق مهام** في لوحة التحكم بزر إجراء مباشر، **متأخرات** و**مستحق خلال 7 أيام**.
- **الموردين وكشف حساب لكل مورد**، **بحث شامل**، **سجل نشاط**.
- **سجل تدقيق** غير قابل للتعديل (قبل / بعد) وحماية السداد الزائد على مستوى قاعدة البيانات.
- تقارير: **أعمار المستحقات**، **كفاءة الدورة**، **الإنفاق حسب البند**.

> **بعد أي تحديث للموقع:** شغّل ملف `supabase/schema.sql` تاني في Supabase (SQL Editor ← Run). الملف آمن لإعادة التشغيل وبيضيف الجديد بس من غير ما يمس بياناتك.

## التشغيل لأول مرة (مرة واحدة بس)

### 1) تجهيز قاعدة البيانات في Supabase
1. افتح مشروعك على [supabase.com](https://supabase.com/dashboard) ← **SQL Editor** ← **New query**.
2. انسخ محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) كله والصقه، واضغط **Run**.
3. من **Authentication ← URL Configuration** حط رابط الموقع في **Site URL**:
   `https://hesham-mahdi.github.io/Time-Code-Procurement-Finance/`

### 2) تفعيل الموقع على GitHub Pages
الريبو ← **Settings** ← **Pages** ← في **Source** اختار **Deploy from a branch** ← Branch: **main** / **(root)** ← **Save**.
بعد دقيقة أو اتنين الموقع هيشتغل على:
**https://hesham-mahdi.github.io/Time-Code-Procurement-Finance/**

### 3) إنشاء حساب المدير
أول مرة تفتح الموقع هتظهرلك شاشة **"إعداد حساب مدير النظام"**. اكتب اسمك وبريدك وكلمة المرور، والحساب ده هيكون مدير النظام (المالية).
بعدها من **الإعدادات ← إضافة مستخدم** ضيف مدير المشتريات وباقي المستخدمين، وكل واحد بكلمة مروره.

> ننصح من **Authentication ← Sign In / Providers** تقفل **Allow new users to sign up**، لأن المستخدمين بيضيفهم المدير بس.

## الأدوار
| الدور | الصلاحيات |
|---|---|
| المالية — مدير النظام | اعتماد ورفض واستيضاح، تسجيل الدفعات والإيصالات، العرض المالي التقديري، التقارير، إدارة المستخدمين والإعدادات |
| مدير المشتريات | إنشاء مشاريع، رفع فواتير وعروض أسعار، رفع الفاتورة الضريبية، طلب دفعات إضافية |
| الإدارة | مشاهدة لوحة التحكم والتقارير فقط |

الصلاحيات متطبقة في قاعدة البيانات نفسها (Row Level Security)، مش في الواجهة بس.

`https://hesham-mahdi.github.io/Time-Code-Procurement-Finance/?demo`
